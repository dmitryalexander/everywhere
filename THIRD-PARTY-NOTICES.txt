Everywhere is a visual front-end for voidtools Everything and is not affiliated
with voidtools. Everything64.dll is the official Everything SDK library (above).

The page interface (toolbar, search-term bar and pickers) adapts the owner's own
interface code from Pinful. Upstream Pinless has no JavaScript and is not the
source of these files. Pinful is itself a Pinless fork, so Pinless's AGPL-3.0
license is kept in dependency-licenses/Pinless-LICENSE.txt until a review confirms
that no styling or markup derived from Pinless's original templates is included.
The program uses Rust libraries and their transitive dependencies. Their original
license files are reproduced in dependency-licenses/rust/.
Windows components are supplied by the user's operating system.
The tutorial artwork in web/tutorial belongs to the owner and is shared with Pinful
and Individuous.
